About This Demo

This demo showcases a streaming text typewriter effect with live markdown rendering, extracted from the ui-copilot-components codebase.

The implementation uses the exact same flow as the production POC: TypewriterService animates text character-by-character, which triggers markdown parsing on each frame for live formatting.

Key Features:

  • Adaptive animation speed (catches up when queue builds)
  • GPU-accelerated rendering for smooth performance
  • Blinking cursor (JavaScript-driven, only during idle)
  • Real-time performance metrics
  • Uses exact mock data from codebase
